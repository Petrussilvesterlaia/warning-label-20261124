## The line

> WARNING: This human is 60% water, 40% overconfidence, and 0% able to find its keys in under twenty minutes.

## The idea

A real safety label lists what is inside the product, so this one lists what
a human is made of — in percentages, like a contents panel. The first two
numbers sound reassuringly scientific, and then the last one quietly admits
the truth everyone recognises: the most advanced machine on the planet, and
it still cannot find its own keys. The joke lands in the final few words,
because "in under twenty minutes" turns a small everyday failure into the
one specification this model can never meet.

## Run it

```sh
python3 main.py
```

It writes the single line to `/output/entry.txt`.
